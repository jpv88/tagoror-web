# Desplegar la web en GitHub Pages (5 minutos, gratis)

1. Crea un repositorio público en GitHub, por ejemplo `tagoror-web`.
2. Sube estos archivos a la raíz del repo (index.html, privacidad.html, soporte.html, styles.css).
3. En el repo: Settings → Pages → Source: "Deploy from a branch" → Branch: `main` / `(root)` → Save.
4. En 1-2 minutos la web estará en `https://TU-USUARIO.github.io/tagoror-web/`.

URLs para App Store Connect:
- Política de privacidad: `https://TU-USUARIO.github.io/tagoror-web/privacidad.html`
- Soporte: `https://TU-USUARIO.github.io/tagoror-web/soporte.html`

Antes de publicar, busca y sustituye los dos huecos:
- `[PENDIENTE-EMAIL]` (aparece en privacidad.html y soporte.html)
- `[PENDIENTE: Nombre y apellidos del desarrollador]` (privacidad.html)

Cuando registres el dominio: en Settings → Pages añade el custom domain y estas URLs redirigirán solas.
